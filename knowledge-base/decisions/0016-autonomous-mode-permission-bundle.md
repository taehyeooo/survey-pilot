# 0016 자율 모드 — 권한 묶음 안에서는 묻지 않고 진행

## 결정
- **자율 모드**는 사람이 작업을 맡기고 자리를 비울 때 쓰는 흐름이다. 평소에는 결정과 머지를 사람에게 묻고, 자율 모드일 때만 아래를 따른다.
- **묻는 것은 시작할 때 한 번**: 범위·완료 기준과 **권한 묶음**을 한 메시지로 묻는다. 기본안은 다음과 같다.
  - 머지: 이 작업의 PR은 CI 모두 통과, 커밋·PR 본문에 서명·트레일러 없음을 확인한 뒤 에이전트가 머지
  - 승인 대기로: 공통 모듈 변경, ADR 새로 쓰기·고치기, 기존 ADR과 부딪힘, 유료 API·플랜, 외부 가입·비밀값, 데이터·원격 브랜치 지우기, 범위 밖 일
  - 멈춤: 같은 실패 3번, 사용량 한도
- **권한은 파일에 남긴다**: 받은 답을 spec `## 자율 모드 권한`에 적고, now.md([0015](0015-now-md-handoff.md))에서 링크한다. 새 세션과 하위 에이전트는 대화 기억이 아니라 이 파일에서 권한을 읽는다.
- **그 뒤로는 묻지 않는다**: 답이 없는 결정은 spec에 `가정 n`으로 적고 진행하며, PR 리뷰로 확정한다.
- **권한 밖은 멈추지 않고 비켜 간다**: now.md `## 승인 대기`에 한 줄 남기고, 그 PR은 올리되 머지하지 않으며, 기대지 않는 다음 단계를 계속한다.
- **사용량 한도에 대비한다**: PR을 짧게 나누고, PR마다 now.md에 "어디까지 머지, 다음 무엇"을 미리 적는다.
- **끝은 보고**: 머지됨 / 승인 대기 / 막힘 / 확인할 가정을 now.md와 함께 보고한다.
- CI가 실패한 PR은 자율 모드에서도 머지하지 않는다([0008](0008-enforce-commit-rules-hook-ci.md)). 권한 묶음은 그 작업에만 유효하다.

## 이유
- 사람을 전제한 절차(매번 묻기, 머지는 사람이)는 자리를 비우면 첫 질문에서 멈춘다.
- 결정 하나가 권한 밖이라고 전부 멈추면 나머지 일까지 선다. 승인 대기에 쌓고 계속하는 편이 낫다.
- 세션이 끊기거나 하위 에이전트로 넘어가면 대화 속 허락은 사라진다. 그래서 파일에 둔다.
- 사용량 한도는 예고 없이 끊기므로, 멈출 때 정리하는 것에 기대지 않고 미리 적어 둔다.

## 비교한 대안
1. 모든 머지를 사람에게 남기기 — 다음 PR이 앞 PR에 기대면 충돌이 쌓이고, 돌아온 사람이 머지를 직접 돌려야 한다.
2. 권한 밖이면 멈추기 — 하나 때문에 나머지가 다 선다.
3. 승인 대기를 "답이 필요한 것"에 섞기 — 평소 질문과 섞여 돌아와서 가려내기 어렵다.

## 확인 방법
- 사람 리뷰: 보고를 받을 때 머지된 PR이 권한 묶음 안이었는지(spec `## 자율 모드 권한`과 PR 변경 파일) 본다.
- 커밋 형식·서명은 `scripts/check-commit-msg.sh`(PR CI)가 확인한다.

## 다시 볼 조건
- 권한 묶음 밖의 PR이 머지된 일이 생기면, 머지 전 조건을 CI(변경 경로 검사)로 강제한다.
- 자율 모드를 여러 번 돌려 기본안이 매번 같으면, 기본안을 굳히고 고칠 것만 묻는다.
