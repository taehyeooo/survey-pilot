# 0005 MCP는 실제로 쓰는 것만

## 결정
- 레포의 `.mcp.json`에는 실제로 쓰는 MCP만 등록한다.
- MCP를 새로 넣을 때는 다음 순서를 따른다.
  1. 무료 여부와 한도를 확인한다(확인 날짜·출처 포함, [0002](0002-cost-zero-free-tiers.md)).
  2. 언제 쓰고 언제 쓰지 않는지 정한다.
  3. ADR을 남기고 CLAUDE.md의 MCP 목록을 갱신한다.
- 인증은 가능하면 OAuth를 써서 API 키를 레포나 `.env`에 두지 않는다.
- 외부 MCP에 보내는 질의에는 비밀값과 공개하지 않은 코드를 넣지 않는다.
- 레포가 직접 만드는 MCP도 같은 규칙을 따른다.

## 이유
- MCP 도구 설명은 세션마다 컨텍스트에 들어간다. 안 쓰는 도구가 많을수록 비용이 들고, 에이전트가 엉뚱한 도구를 고른다.
- 무료처럼 보이던 도구가 한도를 넘으면 과금되거나 멈출 수 있다.
- 언제 쓰는지 정하지 않으면 사람마다·세션마다 쓰는 방식이 달라진다.
- 외부 MCP는 질의 내용이 밖으로 나가므로 보내는 것을 가려야 한다.

## 비교한 대안
1. 좋아 보이는 MCP를 미리 많이 등록 — 컨텍스트 비용이 늘고, 실제로 무엇을 쓰는지 알 수 없다.
2. 각자 개인 설정에만 등록 — 팀과 AI가 같은 도구를 쓴다는 보장이 없다.

## 확인 방법
- 사람 리뷰: `.mcp.json`을 바꾸는 PR에 ADR과 CLAUDE.md 목록 갱신이 함께 있는지 본다.

## 다시 볼 조건
- 등록한 MCP를 한동안 쓰지 않았으면 빼는 것을 검토한다.
- MCP 도구를 필요할 때만 불러오는 방식이 보편화되면 "등록 = 비용" 전제를 다시 본다.
