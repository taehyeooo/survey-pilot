# 대응 문서 (runbooks)

알림이 울렸을 때 **사람에게 묻지 않고** 무엇을 볼지·어떻게 조치할지 적는다(ADR 0011·0012). 원인을 다 찾았으면 그 기록은 [troubleshooting/](../troubleshooting/README.md)에 — 대응 문서는 "지금 무엇을 하나", 트러블슈팅은 "왜 그랬나".

## 쓰는 법

- 알림 하나에 문서 하나. frontmatter: `title`, `version`, `status`, `alert`(알림 카드 키).
- 칸: 먼저 볼 것 · 조치 · 끝나면 (켜고 끄는 조치는 켜기 · 끄기). 칸의 목록 줄은 `[자동]` 또는 `[사람 확인]`으로 시작한다 — `check_docs.py`가 검사한다.
- 데이터를 바꾸는 조치는 미리보기 → 사유·재확인 → 실행 순서로 적는다.
