# concepts — 개념 설명

도메인 개념과 기술 개념을 설명한다. 트러블슈팅 2단계("개념은 어떻게 동작하나")에서 알게 된 것 중 다른 문제에도 쓸 만한 것을 여기로 옮긴다. 질문에 답하며 정리한 설명이 다시 쓸 만해도 여기에.

- 파일 이름: `<개념-이름>.md` (날짜 없이, 갱신하며 유지)
- frontmatter: `title`, `version`, `status: active|superseded`, `updated`, `sources`
- 한 파일에 한 개념. 공식 문서 링크를 근거로 단다.
- 새 문서를 쓰면 [index.md](../index.md) "개념"에 한 줄.
